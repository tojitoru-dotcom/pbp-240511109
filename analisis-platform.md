
# Analisis Komparatif Platform

## 1. Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, dan JavaScript | Java, C#, C++, atau Python | Kotlin atau Java untuk Android, Swift untuk iOS |
| Arsitektur | Berjalan melalui browser dan biasanya terhubung ke server | Berjalan langsung di sistem operasi komputer | Berjalan di perangkat seperti HP atau tablet |
| Cara distribusi | Dibuka melalui browser menggunakan alamat website | Diinstal di komputer | Diunduh melalui Google Play Store atau Apple App Store |
| Keunggulan | Bisa dibuka dari berbagai perangkat selama tersedia browser dan koneksi yang diperlukan | Bisa menggunakan file dan sumber daya komputer secara langsung | Praktis digunakan dan bisa memanfaatkan kamera, GPS, serta notifikasi |
| Keterbatasan | Beberapa fitur bergantung pada browser dan koneksi internet | Perlu menyesuaikan aplikasi dengan sistem operasi yang digunakan | Perlu menyesuaikan aplikasi dengan ukuran layar dan kemampuan perangkat |
| Contoh aplikasi | Gmail versi web dan Google Docs versi web | Visual Studio Code dan Microsoft Word versi desktop | WhatsApp dan Google Maps |
